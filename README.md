# Projeto TelePronto

## Nome
Claudio Martins Camilo

## Análise de Acessibilidade
O protótipo foi desenvolvido pensando em usuários debilitados, com possível visão turva ou dificuldade motora. Foram utilizados botões grandes, textos legíveis e fluxo simplificado.

## Fluxo Crítico
1. Usuário abre o aplicativo
2. Seleciona "Consulta Agora"
3. Realiza triagem rápida
4. Entra na sala de espera virtual
5. Inicia consulta por vídeo
6. Recebe receita digital

## Prevenção de Erros
O botão de encerramento da consulta foi mantido isolado para evitar cliques acidentais.
Informações importantes permanecem visíveis durante todo o fluxo.
